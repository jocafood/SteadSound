# SteadSound

> **Explore the universe through sound.**

## English

### Overview

**SteadSound** is an interactive web application that transforms
astronomical images into sound. It allows users to explore images
captured by space telescopes and other NASA astronomical missions---such
as the **Hubble Space Telescope** and, as imagery becomes available, the
**Nancy Grace Roman Space Telescope**---through an experience that
combines visual exploration and sonification.

Instead of simply looking at an image, users can move their cursor
across it and listen as the application turns the information in the
image into sound in real time.

### How it works

1.  **Image selection:** The application displays an astronomical image
    obtained from a NASA source.
2.  **Pixel interaction:** As the user moves the cursor over the image,
    SteadSound reads the data associated with the pixel beneath.
3.  **Sound generation:** The application maps image properties---such
    as the RGB color obtained---to audio parameters, generating
    a sound that changes as the cursor moves.
4.  **Listening and discovery:** Users can listen to the resulting
    sounds and explore the image in a different way.

The exact relationship between image data and sound can be configured as
part of the project. For example, brightness could influence volume or
pitch, while color channels or cursor position could affect other
characteristics of the sound.

### Purpose

SteadSound aims to make astronomical imagery more engaging and
accessible by adding an auditory dimension to visual exploration. It
offers a different way to experience images of the universe, encourages
curiosity, and introduces **sonification**---the representation of data
through sound---as an interactive tool for science communication and
exploration.

### Key features

-   Browse and display astronomical images from NASA sources.
-   Explore images interactively by moving the cursor across their
    pixels.
-   Generate audio in response to the image data beneath the cursor.
-   Translate visual properties into changing sound parameters.
-   Combine visual and auditory exploration in a single web experience.

### Project vision

SteadSound seeks to create a bridge between astronomy, technology, and
sound. By turning image data into an audible experience, the project
invites users to discover details in astronomical images not only with
their eyes, but also with their ears.

## Español

### Descripción general

**SteadSound** es una aplicación web interactiva que transforma imágenes
astronómicas en sonido. Permite explorar imágenes capturadas por
telescopios espaciales y otras misiones astronómicas de la NASA ---como
el **Telescopio Espacial Hubble** y, conforme haya imágenes disponibles,
el **Telescopio Espacial Nancy Grace Roman**--- mediante una experiencia
que combina la exploración visual con la sonificación.

En lugar de limitarse a observar una imagen, el usuario puede mover el
cursor sobre ella y escuchar cómo la aplicación convierte la información
visual en sonido en tiempo real.

### ¿Cómo funciona?

1.  **Selección de imágenes:** La aplicación muestra una imagen
    astronómica obtenida de una fuente de la NASA.
2.  **Interacción con los píxeles:** Cuando el usuario mueve el cursor
    sobre la imagen, SteadSound lee los datos asociados al píxel que tiene debajo.
3.  **Generación de sonido:** La aplicación relaciona características de
    la imagen ---como el código RGB obtenido--- con
    parámetros de audio para generar un sonido que cambia conforme se
    mueve el cursor.
4.  **Escucha y exploración:** El usuario puede escuchar los sonidos
    generados y descubrir la imagen desde una perspectiva diferente.

La relación exacta entre los datos de la imagen y el sonido puede
configurarse como parte del proyecto. Por ejemplo, el brillo podría
modificar el volumen o el tono, mientras que los canales de color o la
posición del cursor podrían influir en otras características del sonido.

### Propósito

SteadSound busca hacer que las imágenes astronómicas sean más atractivas
y accesibles al incorporar una dimensión auditiva a la exploración
visual. Ofrece una manera diferente de experimentar imágenes del
universo, despierta la curiosidad e introduce la **sonificación** ---la
representación de datos mediante sonidos--- como una herramienta
interactiva para la divulgación y la exploración científica.

### Funcionalidades principales

-   Explorar y mostrar imágenes astronómicas provenientes de fuentes de
    la NASA.
-   Interactuar con las imágenes moviendo el cursor sobre sus píxeles.
-   Generar audio en respuesta a los datos de la imagen que se
    encuentran bajo el cursor.
-   Traducir propiedades visuales en parámetros de sonido cambiantes.
-   Combinar la exploración visual y auditiva en una sola experiencia
    web.

### Visión del proyecto

SteadSound busca crear un puente entre la astronomía, la tecnología y el
sonido. Al convertir los datos de una imagen en una experiencia audible,
el proyecto invita a descubrir los detalles de las imágenes astronómicas
no solo con la vista, sino también con el oído.
